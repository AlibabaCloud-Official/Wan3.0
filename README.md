# Wan 3.0: Leading AI Video Generation Model

[Wan 3.0](https://wan.video/) is a state-of-the-art AI video generation model powered by Alibaba Cloud. It pushes the boundaries of video synthesis by delivering cinematic realism, advanced editing capabilities, and comprehensive multi-modal generation tools.

---

## 🌟 Key Features

* **Native 30s Duration**: Supports seamless 30-second video generation with intelligent duration control, enabling full storytelling and creative freedom.
* **Omni-Creation**: Generates video content from up to 20 reference assets, including complex documents, webpage parsing, text, and images.
* **Cinematic Realism & Sound**: Enhances visual texture, physical dynamics, and integrated sound design for immersive audiovisual quality.
* **Pixel-Perfect Consistency**: Accurately preserves character and reference details across frames to maintain production-grade certainty.
* **Precision Video Editing**: Offers instruction-based and reference-based video editing, supporting multi-person/human-object interactions and auto scene splitting.
* **Portrait Customization**: Fine-grained control over bone structure, eye details, and subtle facial expressions.
* **Sequential Storytelling & Interactive Editing**: Generates up to 12 sequential images with cohesive styling, alongside pixel-level box-selection editing.
* **Advanced Text Rendering**: Renders long-form text across 12 languages, including support for complex charts, formulas, and infographics.

---

## 🚀 Quick Start & Modes

Wan 3.0 offers multiple creative pipelines:

| Mode | Description |
| :--- | :--- |
| **Text to Video** | Cinematic precision driven by complex prompt execution. |
| **Image to Video** | Converts static images to 30s clips with auto scene splitting. |
| **Reference to Video** | Casts multi-character references into new dynamic scenes. |
| **Video Editing** | Re-creates visuals, storylines, and environmental elements based on prompts. |
| **Text to Image / Image Edit** | High-fidelity photorealistic generation and conversational image editing. |
